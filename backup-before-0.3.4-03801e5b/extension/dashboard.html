Using the bridge

Open any two ChatGPT or Nomi conversations in separate Edge tabs and sign in normally. Refresh both tabs once after installing the extension, then select them above.

The selected first speaker needs an existing reply. Send an opening message in that chat yourself if needed, then press Play. Keep Edge running and the computer awake.

If a chat does not appear or its reply preview is wrong, open the extension on that chat and use its setup preview. Text replies are supported. Audio, images, and attachments are not forwarded.

“Wait after reply stops changing” adds a quiet-time check after the site’s generation indicator clears. Website changes can require updating selectors in setup.
