# Chat Bridge has moved

Chat Bridge is now maintained in **[Troub274/nomi-virtual-life, under bridge/](https://github.com/Troub274/nomi-virtual-life/tree/main/bridge)** alongside the Nomi Uploader.

- [Current installation and user guide](https://github.com/Troub274/nomi-virtual-life/blob/main/bridge/README.md)
- [Existing-installation migration instructions](https://github.com/Troub274/nomi-virtual-life/blob/main/bridge/MIGRATION.md)
- [Development and tests](https://github.com/Troub274/nomi-virtual-life/blob/main/bridge/DEVELOPMENT.md)
- [New issues](https://github.com/Troub274/nomi-virtual-life/issues)

The current extension v0.4.3, desktop sources, mode guides and tests have moved. Submit future bridge changes and issues to `nomi-virtual-life`.

For a fresh installation, load `nomi-virtual-life/bridge/extension/` unpacked in Edge. For an existing installation, follow the migration guide and preserve the current extension identity and browser storage; moving to another loaded folder does not automatically migrate API keys, checkpoints or journals.

This former repository remains available for historical commits, release downloads, backups and source provenance. Its [pre-migration source](https://github.com/Troub274/nomi-bridge/tree/ea096e7793697ae31cc8e94c517edb99b4ab4f93) is retained. Local development folders, browser profiles and checkpoints were not moved or deleted.
